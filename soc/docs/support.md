## Getting help

- **Something isn't working?** Run the diagnostics first — they name the missing step:
  `preflight.sh` in the installed plugin (`claude plugin list` or `codex plugin list` prints its path).
- **Questions and bug reports:** through [Exabeam support](https://www.exabeam.com/support-and-services/). Include the host (Claude Code or Codex), the plugin
  version, and the `preflight.sh` output.
- **Security vulnerabilities:** please do not open a public issue — report them privately through
  [Exabeam support](https://www.exabeam.com/support-and-services/).
